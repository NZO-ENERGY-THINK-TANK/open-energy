## Rules and ownership

- This epic is an audit, not implementation. Do not fix findings, copy assets, install dependencies, upgrade packages, or change configuration.
- Allowed document writes: `ignore/E01.md` only. Add findings and evidence under the relevant task.
- Forbidden writes: all other tracked files, especially `apps/backend/**`, `old-nextjs/**`, package files, and the lockfile.
- Frontend checks may generate local frontend build/type-check/router artifacts. Inspect repository status before and after; report generated tracked changes without discarding existing user changes. Do not run formatting or lint autofixes.
- Do not read or print secret values. Determine environment requirements from source and example configuration only.
- Do not send live form submissions or call external integrations. Source inspection does not prove runtime behavior.
- One audit owner maintains this file. Other reviewers provide findings to that owner rather than editing it concurrently.
- Distinguish observed behavior, source-inferred behavior, and unverified behavior.
- Additional exclusions and proposed legacy bug/documentation corrections require user review before implementation.
- Assets/data to copy: none in E01. T04 records exact copy pairs for later tasks.
