### Proxy, authentication and environment requirements

- `apps/frontend/config/public-api.ts:3–9`: explicit public data-path allowlist, GET only, optional trailing slash; query is preserved but not parameter-validated at this boundary. Forms are exact POST-only `/api/submit-contact` and `/api/newsletter-track`; other `/api/` requests get 404, wrong form method 405, missing data-proxy key 503 (`vite.config.ts:22–39`).
- `vite.config.ts:13–19`: Node-only `UPSTREAM_ORIGIN` (default local backend port 8000) must be an HTTP(S) origin without credentials/path/query/fragment. `OPEN_ENERGY_API_KEY` wins over backend-directory `INTERNAL_API_KEY`; Vite `loadEnv(mode, ...)` provides mode/local environment loading and process-environment precedence for the requested names. Never rename keys to `VITE_*` or embed them in browser code. No environment value or secret file was inspected.
- Proxy strips incoming authorization, cookies and `x-api-key`, attaches the configured key only to data requests, removes response `x-api-key`, and turns upstream redirects into 502 without forwarding Location/Refresh (`vite.config.ts:44–64`). Both proxy timeouts are 120 seconds. Python guard requires `X-Api-Key`, returns 424 if unconfigured and 401 for missing/wrong key; only exact public form POSTs bypass it (`apps/backend/app/main.py:49–78`). The guard's query-key comment is stale: implementation reads only the header. Additional `require_api_key` dependency in `security.py` uses 500/403; do not confuse its statuses with the global guard.
- Slash compatibility is mandatory because redirects fail closed. Existing SMP, price/production, suppliers, switching and climate GET callers correctly include `/`, matching their Python `@router.get("/")`; exports and other data paths have no ending slash. Allowlisting both variants does not make both backend variants redirect-free. E02 must use canonical spellings, not enable unrestricted redirect following. Legacy Next proxy followed one redirect within the configured origin (`old-nextjs/app/api/backend/[...path]/route.ts:26–58`); this behavior does not carry over automatically.
- Forecast mismatch: all four legacy forecast data/export URLs contain `/renewables/delivery-4/` (`old-nextjs/lib/api.ts:1031,1043,1093,1109`), but the Vite allowlist only accepts clean `/renewables/` URLs. Python supports canonical plus hidden `delivery-4` and `/forecasts` aliases (`apps/backend/app/main.py:119–134`). E02/E08 should change browser callers to canonical URLs; no backend alias or broader proxy permission is needed. Israel's multiline URL literal also contains a newline; replace the whole literal during adaptation rather than copying it.
- Preview explicitly has no proxy (`vite.config.ts:80–81`). Static/production hosting must supply the same-origin boundary
